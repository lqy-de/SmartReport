# 安全测试样本

仓库只保存模拟样本生成器，不保存原始成绩单。生成器从固定的虚构文字和分值创建 PDF，不读取任何现有报表，也不使用真实身份信息。

在项目根目录安装运行依赖后执行：

```powershell
.\.venv\Scripts\python.exe samples\generate_samples.py
```

在软件中选择 `samples/generated` 文件夹，可导入以下三个文件：

| 文件 | 虚构内容 | 预期结果 |
| --- | --- | --- |
| `demo_skill_a.pdf` | 模拟考生甲，73.75 / 100，两条小分 | 已识别 |
| `demo_skill_b.pdf` | 模拟考生乙，36.25 / 100，两条小分 | 已识别 |
| `demo_signal.pdf` | 模拟考生丙，9 / 20，两道题 | 因独立报告缺少准考证号而待复核 |

姓名、准考证号、单位、工种、日期及分值全部虚构。`DEMO-ONLY-` 前缀表示测试编号，日期固定为 2099-01-01。生成的 PDF 和任何手工放入的样本都被 `.gitignore` 排除。

自动化测试会在 pytest 临时目录生成同类文件，并在内存或临时目录构造参考工作簿和 ZIP。开发者无需取得真实考生数据即可运行测试。

如需适配其他版式，请先用虚构信息重新制作测试文件。不要将真实成绩单、截图、参考表、数据库或压缩包加入仓库；不要使用 `git add -f` 绕过忽略规则。

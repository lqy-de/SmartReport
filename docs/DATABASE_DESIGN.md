# SmartReport SQLite 数据库设计

| 表 | 内容 |
| --- | --- |
| `import_batches` | 批次号、选定路径、开始与结束时间、重复策略、状态及计数。 |
| `source_files` | 导入根、相对路径、相对文件夹、父文件夹、原文件路径、ZIP 成员、来源目录键、SHA-256、导入时间、关联批次、结果与重复来源。 |
| `reference_tables` | XLS 或 XLSX 对应的工作表与单元格值，关联来源文件。 |
| `candidates` | 姓名和准考证原始值。成绩列表及导出访问脱敏列。身份不完整的考试由具体来源和序号区分。 |
| `subjects` | 实际识别到的科目类别。 |
| `exam_records` | 来源文件、考试序号、考生、科目、页范围、日期、时间、单位、工种、当前得分、配分、识别方式、原始字段及核验状态。 |
| `score_items` | 原表项目、步骤、配分、得分、原表扣分、备注和明细页码。 |
| `validation_issues` | 每条成绩的识别及核验问题。 |
| `revision_history` | 核准或改分时的原值、新值、时间和原因。 |
| `export_history` | 导出绝对路径、时间、模板和行数。 |

导入批次对应多份文件，一份文件对应多条考试或一份参考工作簿，考试可包含多条小分。成绩归属通过导入根、相对目录和批次筛选。同目录参考表通过来源目录键关联，ZIP 内使用压缩包路径和成员目录。关联只用于访问参考资料，成绩由 PDF 来源记录和人工核准产生。

写连接启用外键和 WAL。导入文件时在写事务中重新检查内容哈希，防止两次导入同时通过去重检查。只将成功识别的 PDF 或参考表作为已导入内容，这样同一份识别失败的文件在重试时仍会重新处理。

使用 SQLite 文本保存分值和 Python `Decimal` 核验，缺失分值保存为空值。XLSX 数字单元格遵守 Excel 自身精度。准考证原值与工作簿内容保存在本机 SQLite，界面成绩表和导出字段使用脱敏准考证号。

# PDF 版式与模拟样本说明

此文档仅描述解析规则。仓库不发布真实考生的成绩、身份、原文件名或来源样本序号。

| 类型 | 当前识别方式 | 限制 |
| --- | --- | --- |
| 操作技能考核评分记录表 | 标题与表头确定考试边界；坐标表格区分项目、内容、配分、得分、扣分和备注；保存打印总分、合计行和小分页码。 | 特定版式适配；列错位、表头不完整和分值差异进入待复核。 |
| 手信号识别考试报告 | 识别标题、姓名和日期；按坐标对齐题号和得分/配分；保留题数及总分。 | 同一 PDF 内仅在姓名、日期与身份一致时继承操作技能表的身份；独立报告可能缺少身份字段。 |
| 续页 | 保留已识别考试的起止页与明细所在页。 | 无文字层、未识别页面及不可靠归属提示人工核对。 |
| XLS/XLSX 参考表 | 逐工作表读取单元格结果，按来源目录关联。 | 尚未执行自动对账；成绩来源为 PDF 及人工核准。 |

模拟样本生成器 `samples/generate_samples.py` 不读取现有报表。所有身份、单位、工种、日期和分值均为固定虚构数据，详见 [安全测试样本](../samples/README.md)。生成 PDF 在本地用于导入，不进入 Git。

简单合成样本用于可重复的基础回归，不能证明所有真实版式或扫描件均受支持。新的回归资料应以虚构信息重新制作。

# SmartReport 测试说明

## 可公开的回归数据

当前自动化测试完全使用合成数据，不扫描项目上级目录，不读取或复制真实考生报告。pytest 会在临时目录创建 PDF、参考工作簿、数据库、ZIP 和导出文件。

原有真实样本验收记录中的分值、样本序号和关联细节已从公开版本移除。此文档不作为真实考试数据或个人成绩的发布渠道。

## 运行方法

安装 `requirements-dev.txt` 后，在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m pytest
```

已有本机 `.deps` 依赖时也可在 PowerShell 执行：

```powershell
$env:PYTHONPATH = '.deps'
python -m pytest
```

## 自动化覆盖

2026-11-18 在 Windows / Python 3.12 环境完成验证：18 项测试全部通过。openpyxl 发出 28 条 `datetime.utcnow()` 弃用警告，不影响本次测试结果。

- 文件夹递归扫描、来源字段、同目录参考表关联、SHA-256 去重与重新导入。
- 显式 ZIP、成员目录保留、路径穿越和异常压缩比拒绝。
- 加密 PDF、损坏文件、缺失路径、未知扩展名和缓存排除。
- 模拟 PDF 的总分、小分、待复核状态、SQLite 落库和 XLSX 汇总回读。
- XLSX/CSV/TXT 中文、小数分值、百分比及公式形态文本处理。
- 文件夹选择、目录与文件拖放、后台导入时界面事件处理、目录筛选后导出。
- 使用本地临时 bare 仓库验证同步脚本成功、未提交修改拦截、分叉拒绝、缺失/重复远程地址和分离 HEAD。

合成样本包含两份操作技能表与一份独立手信号报告。独立报告缺少准考证号，应进入待复核。简单样本不覆盖全部复杂跨页表格或真实场景。

## 同步脚本验证

`sync_repos.bat` 使用 Windows CMD 与 Git 执行，校验当前分支、未提交修改、独立远程地址、每个平台的推送退出状态及远程 Commit ID。不执行添加、提交或强制推送。

维护脚本时应使用临时本地 bare 仓库验证双远程成功、未提交修改阻止推送、缺少 remote、分支分叉导致单个平台推送失败，以及分离 HEAD。测试不得修改正式远程仓库或上传真实数据。
